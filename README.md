# Multi-Material Prosthetic Pylon Cover System

This is a personal project I've been working on for my father, who is a bilateral amputee and uses prosthetic legs.

The project originally started because of the pylon section of his prosthetics. The pylon is obviously much thinner than the rest of the leg, and even underneath pants it can leave that part of the leg looking really thin. I wanted to see if I could design something myself that would give it a more natural shape without interfering with the actual prosthetic.

I ended up designing a set of removable covers that fit around the pylon. I modeled them myself, printed them, assembled everything and then fitted and tested them on his actual prosthetics.

## Where the project is now

The first version works and I'm happy that I was able to take the idea from basically nothing to an actual physical part that he can wear.

At the same time, actually making and testing it showed me quite a few things I want to change. I don't really consider the current design a finished product, more like the first real prototype.

The current covers are mostly rigid printed shells. They give the pylon more shape and still leave access around the prosthetic, but I think the attachment system, fit and overall construction could be a lot better.

There are also more separate parts and assembly involved than I'd like.

## What I want to do next

The next step is basically to start over from what I've learned with this version and see how much better I can make it.

One of the biggest things I want to experiment with is using more than one material in the actual design. Instead of making everything out of the same rigid material, I want to test combinations of rigid and flexible materials and see where they actually make sense.

For example, a rigid material could still make up most of the outside shape while TPU could potentially be used around mounting points, contact areas, connectors or other places where some flexibility would be useful. I don't know yet exactly which of those ideas will make it into the final design, and that's kind of the point. I want to actually print them, test them and figure out what works instead of designing around assumptions.

I also want to work on making the covers easier to install and remove, reducing the number of separate pieces, improving durability and making the design easier to change for different dimensions.

## Why I'm interested in the Snapmaker U1

Right now my main personal printer is a Flashforge AD5X. I've been able to make the current version with it, but there are some things I want to try with this project that are difficult with my current setup.

The U1 interests me mainly because of the independent toolheads and the larger build area.

For the next version I want to experiment with rigid and flexible materials being used together in one part. Being able to have separate toolheads already loaded with different materials would give me a lot more freedom to test that without constantly changing material through the same nozzle.

The reduced material waste from using separate toolheads is also important to me. If I'm going to make a bunch of prototypes while figuring this out, I don't want to throw away a huge amount of filament every time the printer changes materials.

The larger build area would also help with some of the longer parts of the covers and give me more freedom when I'm redesigning them instead of having the size of my current printer determine how I split the model.

If I'm able to develop this using a U1, I want to document the different versions here, including things that work and things that don't.

I think showing the failures is just as useful as showing the final version, especially with something like mixing rigid and flexible materials where I expect I'll have to experiment quite a bit before I find what works best.
